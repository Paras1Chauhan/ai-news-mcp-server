## 📖 About

An AI-powered news aggregator MCP server that lets Claude fetch, summarize and filter the latest news across topics — integrated with Claude Desktop via the Model Context Protocol.

## ✨ Features

- Fetch latest news by topic, keyword or category
- AI-powered summarization using Claude
- Filter news by source, date or relevance
- Real-time news from multiple sources
- Fully MCP protocol compliant with stdio transport
- Works with Claude Desktop on Windows & Mac

## 🛠️ Tech Stack

- **TypeScript**
- **Node.js**
- **MCP SDK**
- **News API**
- **Zod**

## 🚀 Getting Started

```bash
git clone https://github.com/Paras1Chauhan/ai-news-mcp-server.git
cd ai-news-mcp-server && npm install
Add your News API key to .env
npm run build
Add to Claude Desktop config and restart Claude
```
